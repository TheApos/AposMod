Тестуйте на **новому світі** (старий `AposMod` міг зберегтися зламаним). Консоль — **F1**.

## 0. Підготовка

- [x] Гра завантажилась, у консолі (F1) немає червоних рядків з `AposMod`, `XML` або `loot.xml`.
- [x] Можна ходити, світ не провалюється.
- [x] Ваш id гравця: команда `lpi` (знадобиться для спавну зомбі).  
 id-171

- [ ] Удень зомбі повільні — зручніше: `settime day`.

> **Важливо:** режим `dm` (безсмертя) вмикайте тільки для тестів, де зомбі не мають вас бити. Для кастетів він заважає.

### Шпаргалка: спавн і корисні команди (F1)

| Команда | Що робить |
|---|---|
| `se` | список усіх істот з номерами + ваш id |

| `cm` | креативне меню (блоки, скрині) |

| Тип | Назви для `se 171 …` |
|---|---|
| Звичайні | `zombieBoe`, `zombieMoe` |

## 1. Дробовик — куля відкидає

```
giveself gunShotgunT1DoubleBarrel 6
giveself ammoShotgunSlug 1 50
giveself ammoShotgunShell 1 50
giveself ammoShotgunBreachingSlug 1 50
```
Патрон перемикається утриманням **R** (вибір типу).

- [x] **Slug:** зомбі відлітає назад (~2–3 м) і падає.
- [ ] **Breaching slug:** те саме.
❌ відкидуе, але дуже криво якось, приблизно з дистанції 5+ метрів взагалі немає урону.
- [x] **Дріб (shell):** звичайна поведінка, без відкидання.
- [x] Наскільки далеко летить? (занадто слабко / нормально / занадто сильно) → слабко, можна сильніше

## 2. Гранати — радіус ×3 по зомбі

```
giveself thrownGrenade 1 10
giveself thrownGrenadeContact 1 10
giveself thrownAmmoPipeBomb 1 10
```
Заспавніть 4–5 зомбі групою.

- [x] Граната зачіпає зомбі значно далі, ніж раніше (≈15 м для гранат, ≈12 м для pipe bomb).
- [x] Ями в землі/руйнування блоків — **такі ж маленькі**, як раніше.
- [x] В описі предмета радіус показує більше число.

## 3. Молотов — сповільнення і довга калюжа

```
giveself thrownAmmoMolotovCocktail 1 10
```
- [x] Палаючий зомбі йде/біжить **дуже повільно**.
- [x] Калюжа вогню горить помітно довше (≈16 с замість ≈8).
- [x] **Вас** вогонь не сповільнює (станьте в калюжу на мить).

- [x] Наведіть на зброю в інвентарі: під звичайним описом є жовтий блок `AposMod: ...` з поясненням фішки (ножі, біти, кувалди, кийки, списи, кастети, дробовики, кулі, гранати, молотов, ракетниця, pipe-зброя).

- [x] **Ніж:** силовий удар → бафф **Bloodsucker** на 5 с.
- [x] **Саморобна зброя в руках:** бафф **Veteran Junk** з числом бонусу (0, 10, 20…); зникає, коли берете іншу зброю (до 2 с затримки). Кожні 5 вбивств — повідомлення на панелі.
- [ ] **Цифри шкоди:** над зомбі вилітають цифри. Білі — звичайні, **жовті з «!»** — хедшот, **червоні** — вбивство. Від молотова/кровотечі — маленькі цифри тіками.

## 8. Зміни v0.3.0 (за вашими коментарями)

Перки для тесту видавайте через меню навичок або консоль (`help` → команда для рівня перка). Порівнюйте рівень 0 і рівень 5.

### Цифри шкоди (виправлено зміщення)
- [x] Цифри з'являються **над головою** того зомбі, якого вдарили, і не зникають з часом.
- [x] Цифри стали більші й живуть довше (1.5 с) — їх легко помітити.
- [x] Хедшот — жовтий з «!», вбивство — червоний. Давай коліб цифр для вбивства не буде відрізнятись, тобто або білий, або жовтий. Якщо добили, то нехай буде надпис "Труп!" або аналог на англійській. Червоним кольором. це буде індикатором убивства.

### Дробовик
- [x] **Slug** (`ammoShotgunSlug`) відкидає сильніше, ніж раніше.
- [ ] Примітка: **Breaching slug** б'є лише до **4 м** — так у самій грі (куля для дверей), це не баг мода.

### Ножі — стаки регенерації («Глубокие раны»)
- [x] Кожен удар додає стак (силовий +2), число на баффі «Кровопийца» росте, HP відновлюється швидше.
- [x] Максимум стаків: 2 без перка, 3 на 1 рівні … 7 на 5 рівні.
- [x] Бафф зникає через 5 с після останнього удару.
- [x] Вбивство силовою атакою **більше не дає** +20 витривалості.

### Біти («Громила Пит»), кувалди («Дробитель черепов»), кийки («Просчитанная атака»)
- [ ] Біта: оглушення частіше на вищому рівні перка; силовий у голову відкидає далі.
❌ "Громила ПИТ" треба переробити, бо скілл базовий скіл дае відсоток шансу збити з ніг при силових атаках, а ми силові атаки зараз переробили по сути, вони відкидають зомбі.
❌ передивись всі скіли, можливо десь ще така проблема, що наші скилі перекривають стандартні
- [x] Кувалда: збиває з ніг частіше; радіус «Землетрусу» більший (до 5.5 м на 5 рівні).
- [x] Кийок: силовий шок діє на більший радіус і довше (до 5.5 м / 4 с).

### Списи («Мастер копья»)
- [ ] Силовий пробиває 1 зомбі позаду на 1 рівні … 5 на 5 рівні; без перка — без пробиття.
❌ для звичайного удару будуть бонуси скейлитись від скіла?? Без скіла "Мастер копья" також повинент бути мінімальний єффект для коп'я

### Кастети («Драчун»)
- [ ] Удар зомбі по вас дає заряди: 2 без перка, 3 на 1 рівні … 7 на 5 рівні; **таймера немає**.
- [ ] Звичайний удар: +25% і −1 заряд.
- [ ] Силовий: витрачає **всі** заряди, +50% урону за кожен, збиває з ніг; витривалість **не** дає.

### Саморобна зброя
- [x] Кожне вбивство: +2% (число на баффі росте по 2).
- [x] Старий бонус зі збереження не пропав.
- [ ] Максимум +1000%, на ньому одноразове повідомлення.
