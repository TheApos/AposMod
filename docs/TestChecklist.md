# Чекліст тестування AposMod v0.1.0

Тестуйте на **новому світі** (старий `AposMod` міг зберегтися зламаним). Консоль — **F1**.

## 0. Підготовка

- [ ] Гра завантажилась, у консолі (F1) немає червоних рядків з `AposMod`, `XML` або `loot.xml`.
- [ ] Можна ходити, світ не провалюється.
- [ ] Ваш id гравця: команда `lpi` (знадобиться для спавну зомбі).
- [ ] Спавн зомбі: `se <ваш id> zombieBoe` (якщо синтаксис інший — `help se`).
- [ ] Удень зомбі повільні — зручніше: `settime day`.

> **Важливо:** режим `dm` (безсмертя) вмикайте тільки для тестів, де зомбі не мають вас бити. Для кастетів він заважає.

## 1. Дробовик — куля відкидає

```
giveself gunShotgunT1DoubleBarrel 6
giveself ammoShotgunSlug 1 50
giveself ammoShotgunShell 1 50
giveself ammoShotgunBreachingSlug 1 50
```
Патрон перемикається утриманням **R** (вибір типу).

- [ ] **Slug:** зомбі відлітає назад (~2–3 м) і падає.
- [ ] **Breaching slug:** те саме.
- [ ] **Дріб (shell):** звичайна поведінка, без відкидання.
- [ ] Наскільки далеко летить? (занадто слабко / нормально / занадто сильно) → ________

## 2. Гранати — радіус ×3 по зомбі

```
giveself thrownGrenade 1 10
giveself thrownGrenadeContact 1 10
giveself thrownAmmoPipeBomb 1 10
```
Заспавніть 4–5 зомбі групою.

- [ ] Граната зачіпає зомбі значно далі, ніж раніше (≈15 м для гранат, ≈12 м для pipe bomb).
- [ ] Ями в землі/руйнування блоків — **такі ж маленькі**, як раніше.
- [ ] В описі предмета радіус показує більше число.

## 3. Молотов — сповільнення і довга калюжа

```
giveself thrownAmmoMolotovCocktail 1 10
```
- [ ] Палаючий зомбі йде/біжить **дуже повільно**.
- [ ] Калюжа вогню горить помітно довше (≈16 с замість ≈8).
- [ ] **Вас** вогонь не сповільнює (станьте в калюжу на мить).

## 4. Ближній бій

Звичайний удар — **ЛКМ**, силовий — **ПКМ**.

### Ножі — `giveself meleeWpnBladeT3Machete 6`
- [ ] Звичайний удар: +1 HP за влучання (зніміть трохи здоров'я перед тестом).
- [ ] Силовий: на зомбі кровотеча, вам 5 с регенерації (+1 HP/с).
- [ ] Вбивство силовим: +20 витривалості.

### Біти — `giveself meleeWpnClubT1BaseballBat 6`
- [ ] Звичайний: іноді (≈15%) зомбі на мить оглушений.
- [ ] Силовий **у голову**: зомбі відлітає і падає.
- [ ] Силовий не в голову: звичайна поведінка.

### Кувалди — `giveself meleeWpnSledgeT1IronSledgehammer 6`
- [ ] Звичайний: іноді (≈20%) збиває ціль з ніг.
- [ ] Силовий: падають **усі** зомбі в радіусі ~3 м.

### Кийки — `giveself meleeWpnBatonT2StunBaton 6` і `giveself meleeWpnBatonT0PipeBaton 6`
- [ ] Звичайний: короткий шок цілі.
- [ ] Силовий: шок у всіх зомбі в радіусі ~3 м.

### Списи — `giveself meleeWpnSpearT1IronSpear 6`
- [ ] Звичайний: зомбі трохи відштовхує.
- [ ] Силовий: зомбі відлітає; якщо позаду стоять ще 1–2 — їх теж б'є.

### Кастети — `giveself meleeWpnKnucklesT1IronKnuckles 6` (**без `dm`**)
- [ ] Після того як зомбі вас ударив, 3 звичайні удари б'ють сильніше.
- [ ] Силовий протягом 3 с після отриманого удару: дуже сильний, збиває з ніг, +20 витривалості.
- [ ] Силовий без отриманого удару: звичайний.

## 5. Саморобна зброя — ветеран

```
giveself gunHandgunT0PipePistol 1
giveself ammo9mmBulletBall 1 300
```
- [ ] Порахуйте, скільки пострілів у тіло треба на одного `zombieBoe` **до** першого вбивства → ____
- [ ] Після 5 вбивств — менше пострілів (+10%).
- [ ] Після 50 вбивств — помітно сильніше (+100%).
- [ ] Вийдіть з гри і зайдіть знову: бонус **зберігся**.
- [ ] Ремонт саморобної зброї вимагає **брухт заліза** (наведіть на зброю → ремонт).

## 6. Ракетниця і ракети

- [ ] У торговця на старті гри може бути ракетниця (асортимент рандомний — перевірте кількох / після оновлення асортименту).
- [ ] У фінальній скрині будинку є ракети. Кількість за зірками:

| Зірки | Очікується | Отримали |
|---|---|---|
| ★1 | 1 | |
| ★2 | 1–2 | |
| ★3 | 2–3 | |
| ★4 | 3–4 | |
| ★5 | 4–6 | |

Швидкий тест без проходження будинку: увімкніть креатив (`cm` → інвентар → іконка лампочки), поставте блок `cntLootChestHeroInsecureT1` (★1-скриня) і відкрийте його.

## 7. Описи, індикатори, цифри шкоди (v0.2.0)

> Мод тепер має `AposMod.dll`, тому гру треба запускати **без EAC** (у вікні запуску Steam вибрати варіант без EasyAntiCheat). З EAC гра не завантажить DLL.

- [ ] Наведіть на зброю в інвентарі: під звичайним описом є жовтий блок `AposMod: ...` з поясненням фішки (ножі, біти, кувалди, кийки, списи, кастети, дробовики, кулі, гранати, молотов, ракетниця, pipe-зброя).
- [ ] **Кастети:** отримали удар → з'явився бафф **Counter Punch** з іконкою кулака, таймером 5 с і числом 3; число зменшується з кожним звичайним ударом; силовий удар прибирає бафф.
- [ ] **Ніж:** силовий удар → бафф **Bloodsucker** на 5 с.
- [ ] **Саморобна зброя в руках:** бафф **Veteran Junk** з числом бонусу (0, 10, 20…); зникає, коли берете іншу зброю (до 2 с затримки). Кожні 5 вбивств — повідомлення на панелі.
- [ ] **Цифри шкоди:** над зомбі вилітають цифри. Білі — звичайні, **жовті з «!»** — хедшот, **червоні** — вбивство. Від молотова/кровотечі — маленькі цифри тіками.
- [ ] Хедшот справді жовтий (якщо всі цифри білі — напишіть, виправлю визначення хедшоту).
